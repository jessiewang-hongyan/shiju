# 移动窄屏与慢网加载验收

日期：2026-10-29。仅本地验收，没有发布。

## 环境与边界

使用内置浏览器视口 390×844、320×740、375×420；最后恢复默认视口。属于桌面浏览器窄屏模拟，没有验证 iPhone Safari、触摸手势或真实软键盘。375×420 用于检查可用高度缩小时弹窗仍能操作，不声称等同 iOS 键盘行为。

独立临时预览 4187，使用 SHIJU_PREVIEW_CONTROL 指向本机 JSON 控制文件。静态资源按每请求 600 ms + 压缩字节数/400 kbps 延迟，gzip；此模型不是所有并发请求共享总带宽。临时失败开关只对该测试预览的 JSON 返回 503。正文使用已有 Postman HTTP 模拟复测，正常 4185 页面未改变。临时服务器结束后关闭。

## 结果

| 项目 | 结果 |
|---|---|
| 390 像素日间加载提示 | 筛选项、状态与来源说明不重叠，关闭按钮可操作 |
| 320 像素夜览 | document clientWidth=scrollWidth=305（浏览器滚动条占宽），无横向溢出；弹窗位于 x=17..288 |
| 375×420 可用高度 | 弹窗 y=31.5..388.5，在视口内；内部列表可滚动，关闭按钮保留 |
| 夜览加载动画 | 继承低亮度文字色，无白色大面积背景，完成后移除动画状态 |
| 503 失败 | 显示“分片加载失败，请重试”和“重试加载”，动画停止 |
| 恢复网络后重试 | “欧阳修”搜索恢复 1511 篇、首屏 40 条，动画结束 |
| 加载中取消 | 给 JSON 增加 5 秒延迟，输入“陶渊明”，等待 is-loading 出现后关闭；旧结果返回后弹窗仍关闭、动画类仍为空 |
| 过期查询结果覆盖 | library-service 的较新查询优先回归测试通过 |
| 正文 HTTP | 全部 6959 块 SHA 校验通过；404、503、超时、损坏响应和损坏持久缓存恢复通过 |
| 模块测试 | 本轮运行 library-service.test.js 5 项通过；预览服务器语法检查通过 |

正文弱网本轮实测：古文样本 905 ms、楚辞 929 ms、宋库 796 ms。仅为已有搜索结果后的正文阶段，不包含页面、字体或搜索索引首次加载；详见 prototype/remote-body/weak-result.json。

## 尚待优化 / 验证

更新：下述 Worker 取消限制已在后续本地版本修复，见 [旧搜索取消](search-cancellation.md)；真机与线上限制仍保留。

取消现在只移除主线程等待并忽略旧回复，Worker 内的 fetch 未接收取消信号，且 Worker 串行处理任务。代码可见这一限制，连续换关键词时旧下载可能延迟新查询；本轮没有声称取消后流量归零。建议下一步加入 Worker 请求取消/跳过过期任务，保留成功缓存。

减少动态效果的媒体查询存在，本轮未切换操作系统偏好做浏览器实测。真实移动设备 CPU、Safari 缓存配额、系统键盘遮挡及线上源站网络仍需真机验收。
