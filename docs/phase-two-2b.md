# 二阶段 2B：多原文编辑

更新：2026-11-03。状态：本地实现及桌面／窄屏验收完成；未提交、未部署。真实 iPhone／Android、弱网全流程及多原文纸纹／导出不在本次通过结论中。

## 使用方式

本地运行 `node prototype/multi-source/serve.mjs`，访问 <http://127.0.0.1:4200/>。从仓库根目录启动；服务器复用 `release-artifacts/migration-final-site` 的搜索、字体、正文定位资源，不复制整份发布包。`/index.html` 保留旧版入口，用于同源兼容验收。

1. 点击“＋ 添加原文”，沿用搜索或粘贴入口，预览全文或连续选段后确认添加。
2. 每篇形成一个 Tab，显示篇名与已摘字数。切换不会清空集句，也不产生撤销步骤；只渲染活动原文，记录各篇滚动位置。
3. 标题、作者、正文与缺文标记均可裁剪。集句字块携带原文实例、区域和码点位置，两个来源的同字互不影响。
4. 点击原文空位或双击集句字块归还；选中字块后“查看出处”会切换到所属原文并高亮空位。
5. 原文菜单可看完整信息、前移／后移、调整选段、移除。已有摘字时禁用选段修改；移除需确认关联字数，可一次撤销恢复原文和字块。
6. “存入诗集”保存整个作品，列表展示多来源摘要；继续创作恢复全部快照、字块和作品设置。打开作品也可撤销。

同一来源记录再次添加会跳到已有 Tab。自定义原文使用完整标题、作者和原始正文的身份，选段不改变身份。关闭或切换预览后，迟到的添加操作不会修改作品。新选段需要重新获取全文时，关闭弹窗或改变搜索会取消等待并使过期结果失效。

## 实现与存储

- `document-commands.js`：不可变命令、共享快照的 100 步全局历史；普通撤销不回退独立字号等一期设置，撤销打开作品会恢复整份设置。
- `editor-v2.js`：Tabs、单活动原文渲染、出处、全局裁剪／归还、菜单及键盘交互。
- `app-v2.js`：本地入口、作品设置适配、诗集、旧记录导入、备份及保存异常界面。
- `draft-session.js`：合并连续草稿写入、串行诗集操作、冲突后保留内存创作。
- `preferences-v2.js`、`confirm-dialog.js`：复用一期设置控件恢复作品；页面内确认对话框。
- `document-storage.js`：IndexedDB 物理版本 2，逻辑作品仍为 schemaVersion 2。`documents` 按作品存储，`workspace` 保存 ID 和版本元数据，`views` 独立保存页面视图，`backups` 保留迁移／恢复前记录。物理版本 1 升级在事务中备份并拆分。

普通自动保存只写当前作品和轻量元数据。收藏操作与编辑保存共用写入队列，避免本页面快速编辑产生自我冲突。另一页面抢先写入时阻止静默覆盖，提供重载、保留副本、下载备份。旧页仍写旧 localStorage 键，新页检测后可明确导入为独立作品，不替换当前创作。

边界：启动与打开诗集目前仍读取全部收藏；批量迁移／备份恢复仍需完整工作区。此次没有宣称首次打开、真机内存或多原文渲染已经完成容量优化。

## 原生容量实验

[完整原始报告](evidence/phase-two-2b/native-capacity.json)包含浏览器版本、样本与时间。桌面 Chrome，每项 3 次，包含校验与读回；不包含 DOM、纸张与导出开销。

| 数据规模                       | 全工作区写入中位数 | 当前草稿写入中位数 | 当前草稿读取中位数 |
| ------------------------------ | -----------------: | -----------------: | -----------------: |
| 当前作品 10 篇，每篇 3000 码点 |             5.7 ms |             2.7 ms |             1.8 ms |
| 加 10 份同规模收藏             |            47.6 ms |             2.6 ms |             1.6 ms |
| 加 50 份同规模收藏             |           215.5 ms |             2.2 ms |             1.6 ms |
| 加 100 份同规模收藏            |           445.6 ms |             2.4 ms |             1.5 ms |

这证明拆分后草稿保存不会随收藏正文总量一起重写，不等同于移动端性能保证。50／100 份样本的 localStorage 对照出现配额错误；IndexedDB 通过。

## 阶段边界与待验收

2B 允许多原文编辑、保存和 JSON 备份。多原文时暂时采用普通字块显示，隐藏旧单原文图片预览并禁用图片导出，防止按当前 Tab 错误取样或漏掉其他来源。单原文仍复用一期导出路径。

2C 接入按来源布局、独立纸张、相邻纸片和取样；2D 接入多原文导出、预览及范围选择。真实手机触摸、长篇切换性能与纸张组合、完整慢网／离线复验、备份文件选择器恢复 UI、发布包与回退验收仍需后续完成。当前不是二阶段整体发布候选。
