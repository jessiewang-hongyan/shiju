- **花间集数据完整性**：十卷分别为 50、50、50、50、48、50、50、50、49、50 条，实计 497 条。不能直接标注“完整 500 首”；是否为合并条目、缺录或其他原因尚未确认。

- **隋疑似缺字与异题**：17 条正文命中标记；另有三组同正文异题，如《山阴谣》与《山阴民为丘仲孚谣》。先保留定位，判断是否应关联为同一作品。
- **南唐残篇**：第 34 条《谢新恩·樱花落尽春将困》正文含 12 个 `□`，需要保留残缺说明或暂缓导入，不能当成完整文本。
- **署名冲突**：候选《应天长·一钩初月临妆镜》署李璟，现库同正文《应天长》署李煜；候选南北朝《胡无人行》署吴均，现库同正文署吴筠；候选《日出东南隅行》署殷谋，现库同正文署李白。此处仅报告数据差异，不裁定正确署名。

## 分类决定（用户确认）

沿用数据源提供的分类，不自行逐篇改朝代：Werneror 的 `南北朝`、`隋` 原样保留；chinese-poetry 的上级目录 `五代诗词` 下保留 `花间集`、`南唐二主词` 两个文集名。界面可平铺为四个入口，但来源元信息记录上游完整层级。

这里的分类是数据源标签，不表示本项目已独立核定每位作者的年代。不要将 `五代诗词` 目录标签强行写进每位作者姓名，也不把上游 `唐末宋初` 改名为 `五代`。保持原始作者字段和来源，署名冲突进入独立复核清单。

建议先做四类候选预览；默认排除疑似缺字条目，保留同正文的不同文集归属，显式列出署名冲突。本批不进行自动补字、自动改作者或直接上线。未命中质量规则不等于已通过全部审核。

## 审计口径

- 使用 CSV/JSON 解析后的记录数，不直接沿用 README 宣称的总量。
- 完全重复：标题、作者、正文三项完全一致，统计多余记录数。
- 正文重复候选：NFC 规范化后去除空白与 Unicode 标点；未做简繁转换、异体字合并或模糊匹配。因此结果是下界，不是所有重复作品的最终数量。
- 与现库对照范围是 `dist/data/*.json` 完整文集，不包含 `modules/poems.js` 中八篇精选；跨文集相同正文不自动删除，以免误删异题、异署名和不同版本。
- 疑似缺字：标题、作者、正文中出现 ASCII `?`、替换符 `�`、`□`、`〓`，以及空字段。自然问号也可能被标记，必须人工复核；未命中不代表没有错字、漏字。
- 审计明细只保存定位、标题、作者、匹配项与哈希，不重新打包候选正文或现代注释。

## 接入规则与待办

1. 按上述用户确认方案沿用上游分类及原书名；平铺入口与来源层级分开存储，不自行重判年代。
2. CSV 映射题目、作者、内容；JSON 映射 title（缺失时 rhythmic）、author、paragraphs。保留源文件和源序号用于追溯，段落保留原顺序，不凭猜测补缺字。
3. 对缺字及空字段先隔离；按可核对底本修订后记录改动来源，不能用 AI 猜字填充。无作者署名的古典作品需要明确标为佚名，不应静默丢弃。
4. 完全重复可在同一入口去重；正文重复、跨文集匹配先人工复核。一个作品属于多个文集时保留文集归属，后续全库搜索可考虑合并展示。
5. 标明当前数据版条目数，不将组诗记录等同于独立首数，不宣传“全本”或“全五代词”。
6. 审核通过后才生成网站 JSON 与不超过目标 200 KB 的批次，更新文集目录、搜索选项、来源说明及资源完整性测试。
7. 验收每库检索、预览、确认替换、连续段落截取、选字归还、标题作者字体、繁简转换、长文 PNG，以及网络失败续载。此次不执行正式接入。

## 复核与复现

审计脚本：[audit-next-collections.py](../scripts/audit-next-collections.py)。报告：[next-collections-audit.json](next-collections-audit.json)。报告记录每份上游文件的仓库、commit、路径、大小和 SHA-256，同时记录本次现库文件哈希。

从报告 `sources` 中逐项下载 `https://raw.githubusercontent.com/{repo}/{commit}/{path}`（路径需 URL 编码），保存为 `SNAPSHOT_DIR/{repo 的第一段}/{path}`；将 `sources` 数组另存 `SNAPSHOT_DIR/sources.json`。脚本先验证每份快照 SHA-256，再执行统计：

```sh
python3 scripts/audit-next-collections.py SNAPSHOT_DIR /tmp/next-collections-audit.json
```

脚本不联网、不写入站点数据。现库发生变化后交叉重复数量可能改变，应比较报告中的现库哈希。
