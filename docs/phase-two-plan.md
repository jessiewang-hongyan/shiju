# 二阶段开发方案：多原文集句

更新：2026-11-04。状态：2A 数据层、2B 多原文编辑、2C 多原文纸张已本地实现；2D 导出代码与自动化已完成，浏览器和实际 PNG 验收待完成，未部署。实施证据与阶段边界见 [2A 记录](phase-two-2a.md)、[2B 记录](phase-two-2b.md)、[2C 记录](phase-two-2c.md)、[2D 记录](phase-two-2d.md)。依据用户确认的多原文方向及原文 Tab 交互整理；下列默认规则作为实现基线，未实测的容量与性能指标不视为结论。

配套文档：[数据与迁移设计](phase-two-data.md)、[验收清单](phase-two-acceptance.md)。一期现状以[架构](architecture.md)和[最近发布记录](migration-deployment-20261030.md)为准。

## 目标与范围

一份集句使用多篇原文，每个裁剪字保留可靠出处，可归还、定位，保留来源字号和纸张图案；编辑、预览、导出、保存与恢复形成完整闭环。

第一版包括：原文 Tab、添加／切换／排序／移除、跨原文摘字与归还、查看出处、全局撤销、每篇原文纸张覆盖、多原文导出、旧作品迁移、加载失败恢复。沿用已有搜索、繁简转换、字体分片、毛边与手工拼贴功能，不新增全文搜索、搜索服务或文集。

暂不包括：同一来源作品的多个副本或重叠选段、已摘字原文的直接编辑、每篇独立字体与字号、自由拖动导出模块、自动多图分页、云端同步、多人协作。不同来源版本的同名作品仍可同时加入。

## 核心交互

页面保持上方集句、下方原文。原文区采用 Tab，每项显示篇名与已摘字数，例如「山居秋暝 · 5 字」。当前项高亮；长篇名截断，完整篇名、作者、文集通过可点击详情查看，不能只依赖悬停。无题显示界面占位“无题原文”，不把占位写入作品或图片。

- 切换只改变当前查看的原文，集句和所有空位不变，保留各篇滚动位置；切换不占用撤销记录。
- 移动端 Tab 栏横向滚动，“＋添加原文”固定可见，菜单按钮有独立触摸区域。
- 使用语义化 tablist/tab/tabpanel，标注当前项；方向键、Home/End 切换 Tab，Tab 键进入内容。不得与集句字块的方向键移动混用。
- Tab 菜单提供完整信息、这篇的纸张、调整选段（符合条件时）、前移／后移和移除。排序必须有按钮方式，拖动不是唯一入口。
- 初始作品仍使用一期默认原文。允许移除最后一篇：显示空原文区和添加入口；没有裁剪字时沿用保存限制，不生成无意义的空图片。

### 添加与重复识别

点击添加，复用现有搜索弹窗：搜索摘要 → 打开全文 → 选择全文或连续片段 → 确认添加。默认添加并激活新 Tab，不清空集句；自定义原文同样进入此流程。

确认成功前保持当前作品不变，读取失败不创建空 Tab；支持重试与取消。关闭弹窗、改变查询或选另一作品后，过期请求不得自动添加或替换任何原文。防止重复点击确认添加两次。

同一来源记录已经加入时，显示“已加入”，可跳到相应 Tab，不再次添加。来源版本不同的记录分别保留，不根据同名、同作者或相似正文猜测重复。自定义原文按标题、作者、原始正文识别完全相同的输入，只统一换行符，不合并异体字或繁简字。

同一来源记录第一版只允许一个选段。未摘字时可重新选段；有摘字时禁用直接改段，提示归还相关字或移除原文后重新添加。按需重新获取全文失败时保留已有选段，不让旧快照失效。

### 出处、归还与撤销

| 操作                 | 结果                                                                             |
| -------------------- | -------------------------------------------------------------------------------- |
| 点击原文字或缺文标记 | 摘取该位置一次；标题、作者、正文均支持                                           |
| 点击空位             | 归还对应字，集句同步移除                                                         |
| 双击集句字块         | 归还到所属原文，所属 Tab 不必打开；不强制跳转                                    |
| 选择字块 → 查看出处  | 激活所属 Tab，定位并短暂高亮空位；移动端可用                                     |
| 清空集句             | 清除集句内容，全部裁剪字归还；保留 Tab、原文和设置，保留标题与署名，沿用现有行为 |
| 移除未摘字原文       | 直接移除，可撤销                                                                 |
| 移除已摘字原文       | 提示“移除这篇原文将同时移除集句中的 N 个字”，确认后原文及关联字块一起移除        |
| 撤销移除             | 恢复原文、Tab 次序、纸张覆盖、字块原位置；恢复后激活该原文                       |

全局按时间撤销一次完整操作，不能分别维护各 Tab 的撤销栈。摘字、归还、排序、添加、移除、允许的选段修改均可撤销。新增的作品内纸张覆盖与导出选择也纳入可恢复状态；一期其他设置不顺带扩展为可撤销。滑块一次拖动合并为一步，不能每个 input 事件保存一次整篇历史。刷新后的撤销历史不保留，沿用一期边界。

## 纸张、字体与相邻纸片

保留“排版、文字、纸张、拼贴”四组设置。

- 字体、字号、文字转换、毛边和手工拼贴强度统一控制。标题、作者、正文原有字号比例继续保留。
- 原文有统一默认纸张设置，每个 Tab 可以覆盖纸张种类、无纹理时的背景色、纸纹深浅；提供“跟随默认”和“恢复默认”。已覆盖的设置不被全局默认变化覆盖。
- 第一期字体颜色的配置能力保留并作为共享默认，不扩展每篇独立墨色；纸张自身派生的颜色按现有逻辑解析。
- 有纹理时隐藏对应背景色控件，保留其值以便切回纯色。夜览仍是页面显示偏好，与导出颜色分开。
- 集句底纸独立；从哪篇原文剪下的字，就保留那篇原文对应位置的图案及来源字号。
- 纸片连接要求：同一原文实例、同一区域、原始位置连续、顺序保持、来源处于同一视觉行，且集句中也未跨换行。手动空格／标点、跨篇、跨标题作者正文、倒序均打断连接。
- 原文相邻空位连接采用同一来源与行规则；纸片内部字距不受拼贴间隔影响。
- 字号、字体、选定纸张或排版变化后重新计算位置，沿用用户已认可的重新取样逻辑。Tab 切换本身不能改变纸纹。

需要提取统一的来源布局与纸纹取样接口。不能依赖当前可见 DOM 才找到其他 Tab 的来源位置，也不能长期渲染全部隐藏长文。编辑、预览、导出共用身份、分组和取样规则，各视图按自己的布局计算坐标，不承诺不同宽度下逐像素一致。随机纸纹、毛边与手工偏移使用持久稳定种子，避免每次切换、刷新或预览重新随机。

## 图片排版与预览

“原文”扩展为“原文组”：竖屏支持集句在原文组上／下；横屏支持集句在原文组左／右。原文组内部第一版纵向排列，各篇保持独立背景，不横向无限增加列数。保留仅集句和仅原文。

默认导出实际贡献裁剪字的原文，提供切换为手动选择；自动模式随摘字／归还实时变化，手动模式保持用户选择。仅原文同样可选择未摘字原文，选择为空时阻止导出并给出具体提示。

默认原文顺序跟随 Tab，用户可切换为自定义顺序，并一键恢复跟随。移除原文时同步清理其导出选择，不能产生失效引用；自定义顺序中新增被选原文追加到末尾。关闭某篇原文的导出不会改变它贡献的字块及纸张取样。

布局只在相关时显示控件：两个主模块存在时显示集句与原文组间隔；至少两篇原文导出时显示原文间隔；保留模块内部留白。仅集句保留用户填写的标题；不恢复一期已移除的编号、说明性标签和摘字统计。

设置预览读取当前作品：每部分最多两行，原文预览有独立的来源切换入口，不改变编辑区当前 Tab；另用模块示意表示完整导出顺序及包含范围。导出按完整内容计算，不能误用截断预览数据。

导出开始时冻结作品与设置快照，计算全部必要来源布局（包括只导出集句时的来源），加载实际需要的字体分片，再绘制。先预估尺寸和内存；沿用现有 24,000 像素单边、64MP 上限，但不得将其当作移动端安全内存保证。超限明确提示减少原文、缩短选段或调整字号，不静默截断。导出失败保留创作并恢复按钮状态。

## 存储、性能与容量

详细设计见数据文档。旧作品自动变为单 Tab，新作品使用有版本号的格式并与旧存储键隔离，回退旧版不允许破坏新版数据。原文快照随作品保存，恢复创作不依赖联网；没有提前缓存的字体和搜索数据不承诺离线可用。

容量不在本方案中未经实测写死为“最多 N 篇”。第一版先以 1、3、5、10 篇为验收矩阵，分别覆盖短诗、已有单篇上限附近文本、重复作者和不同纸张；结合体积、撤销内存、浏览器存储和导出峰值，确定发布上限及界面提示。现有单篇长度规则也需按各导入路径核对，不能假定搜索导入与自定义输入完全相同。

优先只渲染活动原文；后台以纯布局数据处理非活动来源，缓存需有上限和明确失效条件。字体加载合并去重、导出按真实字符集合加载，不因加入原文下载全量字体。继续使用摘要搜索与打开全文时按需请求，禁止一次下载全部正文。

## 核心交付场景

从三篇原文摘字形成一首集句；切换 Tab、调整字号、重新排序、归还、撤销及刷新后出处和空位正确；导出集句及三篇挖空原文，保留各自纸纹。旧版单原文作品打开后不丢字、不串位、不改变题目与署名。
