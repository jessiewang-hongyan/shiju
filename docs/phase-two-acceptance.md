### 本地弱网与断网专项（2026-11-05）

[完整浏览器检查与请求记录](evidence/phase-two-review/network.json) · [恢复后的工作区](evidence/phase-two-review/network-recovered.jpg)。使用独立随机端口、无 HTTP 缓存、真实编辑页和搜索 Worker；索引和字体来自本地发布资源，正文使用固定版本的本地镜像并经过原 SHA-256 校验。代理将待测请求延迟 900 ms，观察请求到达后断开套接字，离线期间拒绝应用请求。没有更改操作系统网络，也没有模拟蜂窝带宽或断开公网 GitHub 服务。

- 搜索《关雎》途中切断索引：未增加空 Tab；恢复后按“重试加载”找到《关雎》。缺点是错误文案显示英文 Failed to fetch。
- 打开《关雎》时切断正文：提示“正文暂时无法连接，请重试”，作品未变；恢复连接再次点击同一结果，加载成功。在预览中再次断网，仍可确认第 1 段并加入第二篇。
- 中断霞鹜文楷 WOFF2 请求：出现失败重试提示。恢复后点击提示，实际 FontFace 已加载，图片预览恢复。文案重复“点击重试”。
- 离线存入诗集；已打开的编辑页中更改临时题目，再离线从诗集打开收藏：标题、两个 Tab 和混合字序“空关”恢复。
- 断网重新访问网址：入口 HTML 无法加载，未通过离线冷启动。恢复网络再访问，原草稿、收藏、来源和空位仍在。这个结论适用于当前本地 no-store 验收环境；页面当前无可靠的离线入口机制。

复现：在仓库目录启动 `node prototype/multi-source/serve.mjs`（4200），另启 `node prototype/multi-source/network-server.mjs`，打开打印的地址并点击“运行本地验收”。每次使用新端口的空工作区。该夹具未接入正式页面。

## 固定验收素材

- A／B／C 三篇短原文，至少两篇包含同一个字且有多个重复位置，标题与作者也包含重复字。
- 一篇带 `□■〓�` 缺文标记的自定义文本；一篇包含非 BMP 字符和换行的文本。
- 一组同名同作者但来源记录不同的作品；同一来源记录重复选择；相同及不同的自定义输入。
- 一组 1、3、5、10 篇作品，短文与接近各导入路径现有长度限制的长文分别测试。
- 来源纸张使用纯色、洒金、带局部图案的花笺；来源字号覆盖标题、作者、正文。
- 固定一期草稿与诗集样本：空标题、署名、全三类来源位置、缺文、插入标点、已选字符、不同纸张；不得用现有正式域名用户数据做破坏性测试。

## 性能与发布门槛

按 1／3／5／10 篇、短文／长文、纯色／复杂纸张的矩阵采样；记录设备、浏览器、冷热缓存、网络条件、原始数据与统计口径。重点记录 Tab 切换至可交互耗时、输入延迟、DOM 数量、存储写入、撤销与布局缓存内存、字体传输、导出耗时和峰值。只有活动原文应持有完整交互 DOM，不允许切换越多占用无界增长。

网络测试覆盖正常、慢网、超时、断网恢复以及关闭弹窗后的迟到响应。已有草稿不应依赖搜索服务正常才能打开。桌面浏览器、窄屏模拟与 iPhone／Android 真机结果分开写；模拟通过不能冒称真机通过。

2A 完成存储选型和初步容量测量；2C／2D 完成布局与导出测量后确定篇数、总文本、历史字节预算及设备降级阈值，并写回方案。发布前这些门槛不得仍标为待定。已有 24,000 像素／64MP 上限之外，需有实测依据的更保守移动端保护。

下列问题阻止发布：来源错配、同字串位、归还或撤销错误、旧数据损坏、保存失败伪报成功、旧页覆盖新版、纸纹跨篇串用、导出静默截断、损坏作品静默丢弃。其他未通过项必须明确范围、影响及处置，不能只写“基本通过”。

## 执行记录模板

每个编号记录：提交号、测试素材、环境、操作、预期、实际、通过／失败／未测、证据路径、缺陷链接与复验结果。视觉项至少保留编辑截图、预览截图和真实 PNG；不能仅验证 DOM 或下载动作发生。

发布候选应在独立端口完成：旧版作品备份 → 迁移 → 多原文编辑 → 保存恢复 → 导出 → 本地回退旧版 → 恢复新版。重新测量正式包体和兼容版本预算，不能把当前约 950 MB 的过渡包再无条件叠加完整一代资源。不得为通过空间限制擅自删除仍在支持的旧资源。

交付物：三份二阶段文档的最终版、迁移与恢复说明、自动化报告、浏览器与真机证据、容量测量、候选包清单、回退演练结果。2A 数据层已由用户另行授权实施；后续编辑界面与上线仍需对应阶段任务，不由本清单自动触发。
