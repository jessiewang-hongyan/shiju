# 移除诗集与静态包空间审计

二期当前草稿自动保存。编辑页不再提供“我的诗集”或“存入诗集”；下载的完整 JSON 备份仍包含历史作品。恢复含历史作品的备份时可选择整个工作区，或只取其中一首作当前草稿；单首取回支持撤销。旧版包及浏览器的旧收藏不删除。

## 可减掉多少部署空间

数值按文件逻辑大小、十进制 MB。上一版二期候选为 950,308,936 B。删除一个界面不会明显改变实际部署压力。[实测明细](evidence/phase-two-size/size.json)来自一期固定发布清单和实际分片，二期继续使用同一批资源。

| 项目 | 实测 | 建议 |
| --- | ---: | --- |
| 静态索引与摘要，含兼容版本 | 875.02 MB | 优先处理，比图片和代码有效 |
| 较早版本的索引、摘要及配置 | 460.31 MB | **潜在**节省；属于仍保留的 15a52e2940ed593e 读取器。先验证退役政策、旧标签页和独立回退包，再考虑退出前台站点。不要删当前生产版或唯一回退包。 |
| 当前索引与摘要中的 gzip + Base64 分片 | 72,624 个 | 逐文件解析并解压验证。只保留原 gzip 字节，毛节省 105,212,135 B。需要新版读取器、路径与完整性契约；旧读者若仍需 JSON，两份并存时不会有此净收益。 |
| 全部按需字体 | 71.37 MB | 已按需加载；不建议为省空间先移除用户可选字体 |
| 图片素材 | 1.76 MB | 收益很小 |

最安全的下一步是为一个文集做二进制读取对照，用原有查询检查结果、弱网重试和旧客户端兼容。如果目标是立即大幅削减正式站点，优先审计较早兼容版本的退役，保留可独立部署的旧版归档。单纯提高 tar.gz 压缩级别只改变归档，不改变发布站点的 1 GB 预算。上述两项不应直接相加当作本轮实际减量。本轮未更改数据或部署政策。

复现：在仓库根目录运行 `python3 scripts/audit-phase-two-size.py`。

新候选 72f42ed38a93ae68：[站点 950,307,430 B，归档 541,889,857 B](evidence/phase-two-size/package.json)，比上一候选少 1,506 B。124 项测试、模块检查通过。[浏览器九步复验](evidence/phase-two-size/browser.json)：升级／回退／再升级后保留混合草稿；从备份单独恢复旧收藏，再撤销回到原来的双篇草稿。历史备份中的重复条目没有自动删除。

旧资源细分、实测包体与兼容结论见[本地退役审计](phase-two-retirement.md)。
