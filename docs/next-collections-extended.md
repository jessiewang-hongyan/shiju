- 金第 91 条，完颜从郁《西江月 题邯郸王化吕仙翁祠堂》，与现库署为储泳的《西江月》正文重合。

### 接入次序建议

先做**金、元**候选预览：体量较小，可先验证朝代分类、缺字筛选和重复来源展示；随后明、清；宋最后接入完整搜索索引，因为它的条目最多，且与现有宋词重合最多。所有类别先保留源记录身份；完全重复可形成去重方案，正文相同但标题或作者不同的记录须另行复核。

## 审计口径与复现

继续使用上一批相同的正文规范化、完全重复和疑似缺字规则：NFC、去空白与标点，不合并简繁和异体字；标记 `?`、`�`、`□`、`〓` 和空字段。正文相同只代表复核候选，不能自动裁定同作或正确署名。“作者字段差异”仅去掉现库作者的朝代前缀后比较字符串，未合并简繁、别名或佚名写法，也不能直接视为作者归属错误。现库对照包括 `dist/data/*.json`，不含八篇内置精选。

扩展运行还包含原四类，以检查两批候选之间的正文重合。脚本使用逐条 CSV 读取和临时 SQLite 哈希索引，不同时保存全部候选正文；脚本退出后删除临时索引。

按报告里的固定版本及路径下载源文件，保存为 `SNAPSHOT_DIR/{repo 第一段}/{path}`；将报告的 `sources` 数组保存为 `SNAPSHOT_DIR/extended-sources.json`。新 12 个文件除 SHA-256 外，还记录并验证上游 Git blob SHA-1 与字节长度。

```sh
python3 scripts/audit-next-collections.py SNAPSHOT_DIR /tmp/extended-audit.json --extended
python3 tests/audit-collections.test.py
```

原四类默认命令继续可用。回归检查确认原四类的条目、作者、缺字、内部重复和现库重合计数与旧报告一致；小样本测试覆盖带引号的跨行 CSV、编号分文件、跨代排除、简繁区分及跨库重复分组，以及源文件被修改后拒绝审计。

## 接入约束

1. 对疑似缺字与署名差异建立单独复核列表；不猜补、不自动改作者。
2. 宋与现有宋词、元与现有元曲的交叉应保留来源归属；决定搜索展示策略后再去重，不把朝代库当成互斥体裁库。
3. 明、清等大库继续按需分片；正式接入前检查索引、累计内存和中途失败续载，不一次加载全部正文。
4. 先做候选预览或分批上线计划，来源、篇数、抽检结果、缺陷处理规则确认后才生成部署数据。
