## 第一批交互规则

- 新入口放入“本批新增”组，继续支持全部文集搜索；搜索可匹配篇名、作者、文集/卷名、来源书名和正文。简繁搜索仍按原始数据精确匹配，不宣称支持简繁等价检索。
- 预览显示出处与缺文提示；超过 2,000 字且超过 8 段的文本默认开启前 8 段选段，可以修改范围或切回全文。
- 节选位置放在出处信息里，不追加到可摘取的作者或标题字段。原题为空时保持为空，不将导航标签当成古籍题名。
- `□`、`〓`、`�` 可按来源位置裁剪、归还与撤销。后两者及 `□` 都不自动判定为经校勘的古籍原缺；普通问号继续作为标点，不擅自推定缺文。
- 连续选取的缺文标记与普通字一样遵循同一行、原顺序、相邻位置的纸条合并规则；摘取后原文对应位置成为可点击归还的洞。
- 元数据出处和提示不是原文正文，不参与选字；图片保持用户已有的标题/正文排版，不额外加审计提示。

## 验收记录

- 数据：四类数量、字段、逐段正文及缺文数量对照固定快照；分片重组与完整 JSON 相等，单片大小检查通过。
- 自动化：全套 JS 回归覆盖原功能、新文集加载/搜索/确认、无题记录、缺文位置/合并/归还/撤销/草稿与 Canvas 导出调用。实际浏览器 PNG 另行检查，Canvas 替身测试不等于像素验收。
- 发布前进行本地浏览器选文与 PNG 检查；发布后检查 Pages 工作流及线上资源。
- 历史限制：第一批发布时尚无独立全文索引；此项随后已通过按需位置索引与篇名作者小索引改善，见 architecture.md 与 acceptance.md。仍未声称完成 iPhone 真机验收。
