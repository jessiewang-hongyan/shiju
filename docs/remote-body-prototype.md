# 正文独立托管本地原型

> 当前实现已升级为 32 KiB 分块、摘要内定位与加载动画；以下原型第一版数字保留作历史对照。当前结果见 [正文分块与加载体验优化](remote-body-optimization.md)。

日期：2026-10-29。状态：仅本地；未创建远程仓库，未发布、推送或部署。原 4184 精简包和 4181 搜索原型保留。

## 结构与约定

页面、篇名作者索引、摘要、字体和纸张保留在 site；3476 份正文块放入 data。搜索不访问正文源，打开作品才加载配置与正文块。当前块大小沿用最多 128 篇，并非一篇一个请求。

页面内 remote-config.json 固定 indexVersion、sourceVersion、baseURL 和每个正文块 SHA-256。数据 URL 包含版本和内容哈希，不读取上游 latest。正文返回后验证 SHA-256；版本不符、缺文件、错误内容均拒绝，不回退到另一版本。成功结果缓存最多 8 块；浏览器 CacheStorage 不可用时仍可使用内存。失败不缓存，下次打开会再次请求。12 秒超时包含读取响应体。

本原型用 Postman simulation 在 4186 的 /data/ 模拟可跨域访问的静态数据托管；4185 /shiju/ 是独立网页。无需生产搜索服务器。正式托管需 HTTPS、CORS、压缩传输；发布新索引前先上传对应数据，旧版本需保留以支持旧页面。

## 复现

在项目根目录执行（先完成 prototype/release/build.mjs 的精简包构建）：

```sh
node prototype/remote-body/build.mjs
postman simulation run postman/simulations/poem-bodies.sim.yaml --port 4186 --no-history --output ndjson
# 另一个终端
node prototype/remote-body/serve.mjs
# 另一个终端
node prototype/remote-body/test.mjs
```

浏览器打开 http://127.0.0.1:4185/shiju/ 。本地 mock 进程须从项目根目录启动。构建输出路径写入 prototype/remote-body/build.json；数据目录还包含原始数据许可证。只替换生成包内适配器，未改原搜索引擎。
