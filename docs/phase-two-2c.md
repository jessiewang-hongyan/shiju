# 二阶段 2C：多原文纸张适配

更新：2026-11-03。状态：本地实现及桌面 Chrome／390px 窄屏验证完成，未提交、未部署。多原文设置预览和 PNG 导出仍待 2D，真实 iPhone／Android 和弱网专项未在本阶段复验。

## 使用方式

运行 `node prototype/multi-source/serve.mjs`，访问 <http://127.0.0.1:4200/>。本地服务器复用已有发布资源，正式入口不变。

- “图片设置 → 纸张”设置默认原文纸张。
- 选择原文 Tab，打开右侧“⋯”，可为该篇选择纸张、纯色背景或纸纹深浅，点击应用。默认跟随全局，也可独立设置或恢复默认。
- 独立设置不受默认纸张改变影响；应用一次记为一个撤销步骤，拖动深浅滑块不会逐次写入历史。移除后撤销可恢复纸张与字块。
- 集句中的字块保留各自原文对应位置的图案。标题、作者和正文的字块尺寸分别沿用来源字号。
- 原位置连续且集句中仍顺序相邻的字可以连成纸片；跨篇、跨区域、跨行、倒序和插入字符不连接。块间距不改变合并块内部距离。
- 字号、字体、宽度、繁简显示变化会重新排版并取样；仅切换 Tab 不重新随机生成毛边或手工偏移。此行为沿用已确认的背景变化规则。

## 代码与状态

| 模块                       | 职责                                                                 |
| -------------------------- | -------------------------------------------------------------------- |
| `source-layout.js`         | 交互和测量共用原文标记；采集各区域字格的数值坐标；有界缓存           |
| `source-paper.js`          | 覆盖校验、默认解析、来源连续性、纸片分组、稳定种子                   |
| `source-paper-settings.js` | 原文菜单独立设置；加载成功后应用，失败保留旧值；关闭后不执行迟到操作 |
| `editor-paper-v2.js`       | 所有贡献来源的布局和纸纹取样、原文空位、合并块、毛边及手工偏移       |
| `app-v2.js`                | 加载活动及贡献来源字体、连接设置和编辑器、保留单原文导出适配         |

作品仍为 schemaVersion 2，使用已有 `paperOverride` 与 `paperSeed` 字段，不增加数据库版本。覆盖为完整三字段对象或 null；早期文档的逐字段继承已明确调整为整组覆盖。原文标题／作者／正文身份均为稳定实例 ID、区域与码点位置，不使用 Tab 下标或转换后文字作为索引。

页面只常驻当前原文的完整交互 DOM。未打开但已贡献字块的原文按需使用一个临时离屏节点测量，结束立即移除；最多保留 10 篇数值布局，删除来源会清理缓存。字体完成加载、字号、宽度、繁简状态及文本变化会使布局失效。不同来源测量之间让出执行机会，过期渲染不会覆盖最新结果；界面显示更新状态，纸张失败可以重试。

来源纸张以全文纸面为坐标系，滚动容器不改变图案位置。字块画布从相应纸面位置裁取；纸片种子由持久来源种子、区域和位置计算。预览与导出未来应复用身份、分组和取样规则，但不同宽度按各自排版取样，不保证跨视图逐像素相同。

浏览器实验覆盖十竹斋、洒金、深色云纹混用；未访问 Tab 的来源可取样；剪下画布与独立绘制的原纸面采样像素一致；标题／作者／正文隐藏测量与可见位置一致；切换前后画布像素不变；块间距只影响独立块；字号改变使隐藏来源几何失效；毛边及手工姿态切换稳定。

实际编辑器另验：三篇各有独立覆盖，恢复默认只影响该篇，撤销恢复覆盖；刷新恢复纸张和裁剪位置；汇文明朝字体加载；字号 14 → 25；夜览下深色纸张标题与正文对比度；390px 页面无横向溢出。单篇导出实际下载并查看，独立纸张正确，测试完成后撤销移除恢复三篇验收作品。下载事件自动等待曾超时，但文件已成功生成，检查页面成功状态与实际 PNG 后确认。

多原文图片设置预览与导出保持禁用，避免生成遗漏来源的图片。单原文仍走兼容导出器；多来源范围、顺序、仅集句／仅原文及冻结快照导出将在 2D 接入。本轮未改动线上网页、文集或数据仓库。
