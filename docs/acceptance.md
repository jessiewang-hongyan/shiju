# 回归验收

## 每次发布的自动检查

```sh
npm ci --ignore-scripts
npm run check
npm test
```

静态检查覆盖所有模块语法、导入路径、循环依赖与未定义变量。测试使用 Node test runner；DOM 功能测试使用 jsdom，Canvas 记录绘图调用；它们不能代替真实字体栅格化、实际 PNG 下载或手机真机验收。

## 功能清单

| 功能        | 验收点                                                                      |
| ----------- | --------------------------------------------------------------------------- |
| 首屏/旧草稿 | 默认空标题、原文与集句正常；旧存储能读回，设置恢复                          |
| 选字/归还   | 同字不同位置区分；点击空缺和双击集句归还对应字；计数一致                    |
| 编辑        | 调序按钮、方向键、拖拽；空格、换行、标点；清空、撤销；标题署名保存          |
| 诗集        | 无字时提示；保存、恢复、删除；失败不更改已保存列表                          |
| 原文选择    | 精选与八类文集；全部加载、搜索、更多、预览与确认                            |
| 文集失败    | HTTP 错误、超时、坏 JSON/格式；自动重试；保留已载入内容；手动续载不重复     |
| 自选与片段  | 原文输入、非文字校验、连续段落上下界、倒置范围、替换确认、撤销              |
| 繁简转换    | 保持原样/简体/繁体；底层 id 不变，重复字归还仍准确                          |
| 字体        | 宋体、康熙、汇文；加载失败重试、已加载复用、作品增加新字补载                |
| 页面字号    | 输入/加减/滑块、5 与 25 边界、失焦修正、重置                                |
| 夜览        | 开关、三种预设、保存与重开；不影响导出配色                                  |
| 图片设置    | 三种预设、自定义背景/文字/集句背景，非法色值验证，恢复默认                  |
| 图片字号    | 输入/加减/滑块、5–25，原文和集句同时缩放                                    |
| 拼贴/毛边   | 开关、1–100 强度、字形居中、连续字与空缺合并、跨行与乱序不合并              |
| 预览        | 使用当前作品、最多两行、空作品提示；设置更改实时刷新                        |
| 导出        | 三种字体；无题/长标题；原文和新诗完整；长文高度，文件名、署名、下载成功提示 |
| 浏览器布局  | 桌面与窄屏，无横向溢出；弹窗可滚动；iPhone Safari 字体及下载需真机验证      |

## 纸张背景

- 原文/集句独立选择纯色、十竹斋、Lokta、洒金；刷新恢复、恢复默认清除选择。
- 原文裁剪图案按字的位置转移，归还/撤销/换行/重排后取样随对应原文字位更新。
- 毛边、手工倾斜与纹理在同一遮罩和变换内绘制。
- 长文底纹连续，十竹斋只出现一次装饰；不按文本长度分配超长纹理位图。
- 两行预览中可显示来自原文后部的纸片。PNG 等待所选图片加载后再生成。
- 加载失败可重试，快速切换不应被早先请求覆盖。

## 单独导出（2026-10-27）

- 排列方式新增“仅集句”和“仅原文”，预览和提示同步切换并记住选择。
- 仅原文保留已选字的空缺；尚未选字也能导出完整原文，不显示集句署名。
- 仅集句保留标题、署名和拼贴纹理，不显示原文区；仍按虚拟原文排版取样。
- 图片高度只按所选模块计算，原有四种双模块排列保持不变。
