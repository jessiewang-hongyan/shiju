# 回归验收

## 每次发布的自动检查

```sh
npm ci --ignore-scripts
npm run check
npm test
```

静态检查覆盖所有模块语法、导入路径、循环依赖与未定义变量。测试使用 Node test runner；DOM 功能测试使用 jsdom，Canvas 记录绘图调用；它们不能代替真实字体栅格化、实际 PNG 下载或手机真机验收。
