## 3. 发布前必须补齐：真机与完整创作流程

至少各选一台 iPhone Safari、Android Chrome，记录设备、系统、浏览器版本、网络和测试日期。

- [ ] 冷启动：首次打开网页、文集、输入“赤壁赋”；分别记录耗时与下载量，不将三阶段合并成“正文加载时间”。
- [ ] 搜索组合：苏轼/蘇軾、欧阳修、其、春、无结果；三种字段与全部/宋文集叠加；显示更多无重复或遗漏。
- [ ] 连续操作：快速修改关键词、切换范围、关闭/重开弹窗、切到自定义；最后一次操作生效，旧结果不回填，等待状态可结束。
- [ ] 真实移动布局：软键盘弹出、横竖屏切换、列表滚动、关闭和重试按钮可触达；屏幕放大后文字与控件仍可读。
- [ ] 夜览与辅助设置：三种夜览配色、系统减少动态效果；读屏能获得等待/失败状态，减少动态效果时停止旋转。
- [ ] 网络切换：Wi-Fi/蜂窝、断网后恢复、前后台切换；无无限等待或草稿丢失，可重试继续创作。
- [ ] 缓存异常：私密浏览/存储不可用、首次与重复打开、清缓存、旧版本更新；缓存失败不阻止联网使用，不出现混版正文。

## 4. 性能验收口径

- [x] 本地模拟已有结果：正文三个样本约 0.8–0.93 秒，条件为 400 kbps / 600 ms；仅指已有搜索结果后打开正文。
- [x] 历史完整首次查询模拟：400 kbps / 600 ms 下约 10.6–14.2 秒，另有打开文集开销；不是所有搜索都在 1 秒内。
- [ ] 对最终包补测冷/热缓存与高命中单字，统一记录页面启动、文集打开、首次搜索、正文打开各阶段；每组至少 3 次，保存原始结果及中位数/最大值。
- [ ] 真机及目标网络下无崩溃、不可恢复卡死或正常查询超时；性能目标需结合实测确认，不能用桌面模拟给出真机承诺。

网络模拟限制：正文测试是本地 HTTP 延迟模型；窄屏服务器按请求限速，不模拟所有并发共享链路、丢包或手机 CPU。首次文字转换模块 import 无法单独中止；取消后不继续旧查询。同步计算无法即时抢占，已收到的字节不能撤回。
