# 拾句

选择诗词中的字，重新排列成诗。纯静态网页，无需后端服务。

在线使用：https://jessiewang-hongyan.github.io/shiju/

当前正式版本（2026-10-30）：22 个文集、788,438 条来源记录，新增明、清、明末清初；采用压缩摘要和去重索引，正文按需加载。见[本次发布记录](docs/migration-deployment-20261030.md)。以下一期表格保留当时的功能快照。

## 一期边界与验收

- 纯静态站点，无账号、云端同步、公开作品社区或完整离线能力；原文使用本地部署的公开数据，未接入百度百科 API。
- 草稿、诗集和设置仅存当前浏览器。预览最多两行不代表导出截断；纸纹根据各视图自己的原文排版取样，不保证不同布局逐像素一致。
- 当前自动回归 42 项通过；已检查桌面浏览器和窄屏布局。尚未完成 iPhone／Android 真机、全部浏览器版本和极端内存压力专项验收。
- 康熙字典体的网页嵌入及再分发许可仍待确认；这不是已解决的授权事项。资源来源与待确认项见 [字体来源](FONT-SOURCE.md)。

## 本地使用

```sh
python3 -m http.server 4173 --directory dist
```

打开 http://localhost:4173 。草稿和诗集仅保存在当前浏览器；线上网站与本地预览的浏览器存储相互独立，不会自动迁移。

## GitHub Pages

将项目推送到 GitHub 仓库的 main 分支。在仓库 Settings → Pages 中将 Source 设置为 GitHub Actions。
`.github/workflows/pages.yml` 会检出 `release-data.json` 固定的数据提交，运行检查和测试，构建并校验 `_site/` 后发布。正文由独立的公开数据仓库按固定提交提供，页面只在打开作品时下载对应正文块。部署成功后，网址显示在 Pages 设置页与 Actions 部署结果中。

所有资源使用相对路径，兼容 `https://用户名.github.io/仓库名/`。

## 文集加载

正式版只提供“篇名与作者”（默认）、“仅篇名”、“仅作者”，可与文集范围叠加；不再提供全文搜索。繁简通搜，篇名相关度排序。摘要与正文分离：搜索先展示摘要，打开作品时按需读取约 32 KiB 的正文块，并校验版本和 SHA-256。高命中单字使用预排序分页，普通关键词读取小索引。

切换关键词或范围时会取消旧网络请求和排队任务；关闭弹窗不会重新发起旧搜索。成功缓存保留，加载和重试有状态反馈。浏览器中的草稿仍保存在本地。

数据发布记录见 `release-data.json`。生成新数据可参考 `scripts/prepare-search-data.mjs` 及 `prototype/remote-body/`；数据必须先发布，再更新页面引用，保留旧提交，不能覆写旧版本。旧 `dist/data/` 索引与脚本用于既有开发/回归；2026-10-30 的迁移已退役最旧无版本路径，改为保留上一正式运行时及其固定索引；新入口使用独立的压缩索引。

## 开发与维护

源码使用浏览器原生 ES modules：`dist/app.js` 负责组装，功能代码位于 `dist/modules/`。`dist/` 保留编辑器源码；正式发布还需要构建搜索运行时及固定版本索引，不能直接上传 `dist/`。

```sh
npm ci --ignore-scripts
npm run check
npm test
npm run format
```

## 复现正式发布包

检出 `release-data.json` 所列数据仓库与提交至 `.release-data/`，然后运行：

```sh
node scripts/build-release.mjs
node scripts/verify-release.mjs
```

输出 `_site/` 必须是新目录；可通过 `RELEASE_DATA_DIR` 和 `RELEASE_OUT` 指定输入与输出。入口脚本、样式、模块目录和配置均使用版本化名称。验证脚本检查资源引用、字体分片、全部正文校验和摘要映射，并运行真实生产搜索引擎。验收报告保存在本地 `release-artifacts/`，不随站点公开。
