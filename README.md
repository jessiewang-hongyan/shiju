# 拾句

选择诗词中的字，重新排列成诗。纯静态网页，无需后端服务。

在线使用：https://jessiewang-hongyan.github.io/shiju/

## 一期功能（截至 2026-10-28）

已完成选择原文、摘字重组、调整纸张与拼贴、预览、PNG 导出和本地保存的流程。

| 功能     | 当前支持                                                                                                                     |
| -------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 原文     | 8 篇精选及诗经、楚辞、汉乐府、汉诗、魏晋诗、唐诗、宋词、元曲八类文集，共 84,907 条；检索、预览确认、自定义输入、连续段落截取 |
| 创作     | 标题、作者、正文均可选字；点击原文空缺或双击集句归还；拖拽、方向键、按钮调序；换行、空格、标点、清空、撤销                   |
| 作品     | 默认空标题、可选标题与署名；自动保存草稿；本地诗集保存、恢复、删除                                                           |
| 文字     | 保持原样／简体／繁体；页面默认系统宋体；字号 5–25，滑块、加减、数值输入，联动原文与集句正文及图片字号                        |
| 图片字体 | 宋体、康熙字典体、汇文明朝体、莫大毛笔字体、拾句细手写（源自辰宇落雁体）、霞鹜文楷；按需 WOFF2 分片、字体预览、繁体提示      |
| 拼贴     | 开关、相邻字块及空缺合并、独立纸片间距 0–24、毛边强度、手工倾斜与上下起伏；保留标题与作者来源字号                            |
| 纸张     | 纯色、十竹斋笺纸、Lokta 手工纤维纸、仿洒金、浅色云纹、深色云纹、旧新闻纸、微皱牛皮纸；原文与集句分别设置                     |

| 排版导出 | 横屏 4:3、竖屏 3:4；原左新右、原右新左、原上新下、原下新上、仅原文、仅集句；留白 0–120、模块间隔 0–160；导出 PNG             |
| 设置体验 | 排版、文字、纸张、拼贴四组；默认展开排版，折叠摘要实时更新，细项按需显示；当前作品每部分最多两行预览，面板底部可导出         |

横屏支持左右布局，竖屏支持上下布局，二者都可单模块导出。起始画布为 1440×1080 或 1080×1440；长内容按比例扩大画布，不缩小字号，超过 24,000 像素单边或 64MP 提示拆分。

## 一期边界与验收

- 纯静态站点，无账号、云端同步、公开作品社区或完整离线能力；原文使用本地部署的公开数据，未接入百度百科 API。
- 草稿、诗集和设置仅存当前浏览器。预览最多两行不代表导出截断；纸纹根据各视图自己的原文排版取样，不保证不同布局逐像素一致。
- 当前自动回归 42 项通过；已检查桌面浏览器和窄屏布局。尚未完成 iPhone／Android 真机、全部浏览器版本和极端内存压力专项验收。
- 康熙字典体的网页嵌入及再分发许可仍待确认；这不是已解决的授权事项。资源来源与待确认项见 [字体来源](FONT-SOURCE.md)。

## 本地使用

```sh
python3 -m http.server 4173 --directory dist
```

打开 http://localhost:4173 。草稿和诗集仅保存在当前浏览器；线上网站与本地预览的浏览器存储相互独立，不会自动迁移。

## GitHub Pages

将项目推送到 GitHub 仓库的 main 分支。在仓库 Settings → Pages 中将 Source 设置为 GitHub Actions。
`.github/workflows/pages.yml` 会发布 dist 目录。部署成功后，网址显示在 Pages 设置页与 Actions 部署结果中。

所有资源使用相对路径，兼容 `https://用户名.github.io/仓库名/`。

## 文集加载

文集以目标不超过 200 KB 的 JSON 小批次加载（单篇超长内容不截断），最多同时请求两份资源。首批完成后即可选用和搜索；加载途中显示已载入篇数。暂时失败自动重试两次，仍失败时保留已加载内容，点击“继续加载”仅补载未完成批次（同一页面内）。加载完成前，搜索仅覆盖已载入内容。

更新原始 `dist/data/*.json` 后运行 `python3 scripts/split-collections.py` 重新生成分片；分片文件名按内容计算，供浏览器缓存复用。运行 `node tests/library-loader.cjs` 检查失败恢复、缓存与并发限制。

## 开发与维护

源码使用浏览器原生 ES modules：`dist/app.js` 负责组装，功能代码位于 `dist/modules/`。无需构建，`dist/` 直接发布。开发工具仅用于检查和格式化。

```sh
npm ci --ignore-scripts
npm run check
npm test
npm run format
```
