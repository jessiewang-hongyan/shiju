# 第二批纸张预览

仅本地预览；不修改 dist，不发布。使用同一首《山居秋暝》对照，支持纸纹浓度、字号、长文平铺及 PNG 保存。

## 素材

- 云纹压花纸：TextureCan Paper 0014，https://www.texturecan.com/details/158/
- 旧新闻纸：TextureCan Paper 0027，https://www.texturecan.com/details/529/
- 微皱牛皮纸：TextureCan Paper 0023，https://www.texturecan.com/details/463/

预览使用颜色贴图，统一缩放到 300 像素纹理单元，混入米白底；默认浓度 65%；云纹采用四次方淡化曲线，此时实际叠加约 18%，其他两种仍为 65%。调到 100% 时均为原始贴图色彩。不是古纸扫描。

## 字号与取样

用户已确认保留现有规则：摘取状态绑定原文字 ID，字号变化后重新排版并按新位置取样，不冻结摘取瞬间的纸片。预览按同样规则演示。原文空缺与集句纸片都来自当前排版的位置。
